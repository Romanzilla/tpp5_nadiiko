## 1. Опис проєкту
Інтерактивна графічна програма для чисельного моделювання обертального руху твердого тіла (маховика/диска) навколо нерухомої осі під дією зовнішнього моменту сили $M$ з урахуванням моменту інерції $I$.

### Фізична та математична модель
- **Основний закон динаміки обертального руху:**
  $$\varepsilon = \frac{M}{I}$$
  де $M$ — зовнішній момент сили ($\text{Н}\cdot\text{м}$), $I$ — момент інерції тіла ($\text{кг}\cdot\text{м}^2$), $\varepsilon$ — кутове прискорення ($\text{рад}/\text{с}^2$).
- **Кінематика обертання (інтегрування методом напівнеявного Ейлера з кроком $\Delta t$):**
  $$\omega_{n+1} = \omega_n + \varepsilon \cdot \Delta t$$
  $$\varphi_{n+1} = \varphi_n + \omega_{n+1} \cdot \Delta t$$
- **Додаткові фізичні величини:**
  - Кінетична енергія обертання: $E_k = \frac{I \omega^2}{2}$ ($\text{Дж}$)
  - Момент імпульсу: $L = I \omega$ ($\text{кг}\cdot\text{м}^2/\text{с}$)

## 2. Архітектура програми
Код у `main.cpp` розділено на три незалежні модулі:
1. `handleInput()` — оброблення подій клавіатури, миші та закриття вікна.
2. `updatePhysics(state, dt)` — чисельне інтегрування рівнянь обертального руху з кроком часу `dt`.
3. `drawScene()` — візуалізація маховика, спиць, мітки на ободі, траєкторії руху, вектора моменту сили, кнопок інтерфейсу та телеметрії.

## 3. Керування під час симуляції
| Клавіша / Кнопка | Дія |
| :--- | :--- |
| **`↑` / `↓`** (або кнопки `M+` / `M-`) | Збільшити / зменшити момент сили $M$ ($\pm 2.0\text{ Н}\cdot\text{м}$) |
| **`→` / `←`** (або кнопки `I+` / `I-`) | Збільшити / зменшити момент інерції $I$ ($\pm 0.5\text{ кг}\cdot\text{м}^2$) |
| **`0`** | Встановити $M = 0\text{ Н}\cdot\text{м}$ (рух за інерцією) |
| **`P`** (або кнопка `Pause / Start`) | Призупинити / відновити моделювання |
| **`Space` / `R`** (або кнопка `Reset`) | Скинути кут, швидкість і таймер у початковий стан |

## 4. Інструкція зі збирання (Visual Studio + CMake + vcpkg)
1. Переконайтеся, що змінна середовища `VCPKG_ROOT` вказує на каталог встановленого `vcpkg`.
2. Відкрийте папку проєкту у Visual Studio (**File → Open → Folder...**).
3. Дочекайтеся автоматичного встановлення залежності `sfml` через `vcpkg.json` та завершення конфігурації CMake.
4. Виберіть ціль `RotationSim.exe` та натисніть **Build → Build All**, після чого запустіть програму.
